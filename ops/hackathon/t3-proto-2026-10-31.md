## 1. Executive Summary

Task 3 Stage A delivers a complete rewrite of the DayPlay AR Corridor Simulator (`sim/app.js` and `sim/index.html`). The simulator connects the typed-intent pipeline directly to an interactive, walkable first-person field-of-view (FOV) projection of the Mission District corridor.

All rendered placards are strictly verified via the backend zero-hallucination gate (`POST /pipeline`). No simulated or mock pins are rendered without verified `listing_id` entries grounded in the validated real DayPlay corridor dataset (`eval/fixtures/corridor_real.json`).

---

## 2. Changes Delivered in Stage A

1. **`sim/app.js` (Full Rewrite):**
   - Direct HTTP integration with `POST /pipeline` on same origin (`/sim` static mount).
   - Removed legacy `/intent` client-side radius filtering.
   - Grounded geometry engine: corrected `metersPerDeg` computation (`lat = 111320`, `lng = 111320 * cos(lat)`).
   - Dynamic walkthrough: user position advances along Valencia/Mission corridor (heading ~35° NW) with live distance countdowns and dynamic FOV clipping (62° HFOV).
   - Kind badges & styling: distinct icons and badges for `saved`, `event`, and `plan_stop` listings.
   - High-contrast 1920x1080 legible placards with distance meters, start times, and entity IDs.
   - Latency logging: `window.__latencyLog` logs intent submission, pipeline response latency, and DOM render latency.
   - Speed controls: toggle walking state (ON/PAUSED), speed multiplier (1x, 3x, 6x), and corridor reset.

2. **`sim/index.html` (Slim Modern AR HUD):**
   - Clean, dark transparent HUD displaying heading, live coordinates, speed, and active pin count.
   - Viewfinder reticle and compass indicator.
   - Controls bar for walk manipulation during demos.
   - Intent input box (`#q`) with instant submission to `/pipeline`.

3. **`tests/test_t3_sim.py` (TDD Test Suite):**
   - Verifies `POST /pipeline` returns grounded pins for demo queries.
   - Verifies `sim/app.js` consumes `/pipeline`, tracks `__latencyLog`, renders `placard` elements, and excludes legacy mock `/intent`.
   - Verifies `sim/index.html` loads and mounts `app.js`.

4. **`tools/t3_server.py`:**
   - Standalone ephemeral dev server utility for running the simulator on custom ports.
